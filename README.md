# NOVA — SaaS landing page starter

A responsive, animated Next.js marketing page built with Tailwind CSS and Framer Motion.

## Run locally

1. Install Node.js 20.9+.
2. Extract this ZIP and open the project folder in VS Code.
3. Open a terminal in the project folder and run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Production build

```bash
npm run build
npm run start
```

## Deploy to Vercel

Push the project to a GitHub repository, import it at https://vercel.com/new, and keep the default Next.js build settings.

## Customize

- `app/page.tsx` — page content and sections
- `app/globals.css` — colors, layout, responsive styles
- `components/landing.tsx` — animated client-side interface

The included dashboard preview is built with CSS and inline SVG, so it does not depend on remote image assets. Replace the NOVA name, copy, pricing and links with your own product details before launch.
